# 复杂度

算法复杂度用来**衡量算法运行效率和资源消耗**，主要分为两类：**时间复杂度**和**空间复杂度**，统一用 **大 O 表示法（Big O Notation）** 描述。

## 一、时间复杂度（Time Complexity）

表示**随着数据规模 n 增大，算法执行次数的增长趋势**，不关心具体耗时，只看增长快慢。

### 常见复杂度从快到慢排序

1. **O (1) 常数阶**

   执行次数固定，和数据规模无关。

   例：取数组第一个元素、简单赋值。

2. **O (log n) 对数阶**

   规模每次减半，增长极慢。

   例：二分查找。

3. **O (n) 线性阶**

   执行次数和数据量成正比。

   例：遍历一遍数组。

4. **O (n log n) 线性对数阶**

   高效排序算法的标准复杂度。

   例：快速排序、归并排序。

5. **O (n²) 平方阶**

   两层嵌套循环，数据变大后效率急剧下降。

   例：冒泡排序、选择排序。

6. **O (n³) 立方阶**

   三层嵌套循环，一般只用于小规模数据。

7. **O (2ⁿ) 指数阶**

   增长爆炸，n 稍大就无法运行。

   例：暴力枚举子集。

8. **O (n!) 阶乘阶**

   最慢，仅用于极小规模。

   例：全排列暴力枚举。

------

## 二、空间复杂度（Space Complexity）

表示算法**占用内存随数据规模 n 的增长趋势**。

- **O(1)**：原地操作，额外空间固定
- **O(n)**：需要开辟和数据量等大的额外空间
- **O(n²)**：二维数组等

------

## 三、大 O 表示法的核心规则

1. 只保留**增长最快的项**

   O (n² + 3n + 5) → 简化为 O(n²)

2. 忽略**常数系数**

   O(3n) → O(n)

3. 只看**最坏情况**

   比如查找，默认按找不到、遍历全部来算

## 简单排序算法

### 选择排序

1. 从0下标开始，向后看找最小的数的下标，

2. 交换前方有序数列的最后一位的数字。
3. 循环n次

```java
	public static void selectionSort(int[] arr) {
		if (arr == null || arr.length < 2) {
			return;
		}
		for (int i = 0; i < arr.length - 1; i++) {
			int minIndex = i;
			for (int j = i + 1; j < arr.length; j++) {
				minIndex = arr[j] < arr[minIndex] ? j : minIndex;
			}
			swap(arr, i, minIndex);
		}
	}

	public static void swap(int[] arr, int i, int j) {
		int tmp = arr[i];
		arr[i] = arr[j];
		arr[j] = tmp;
	}
```



### 冒泡排序

1. 从头开始，比较相邻两个数
2. 交换位置
3. 直到最后，最大（小）的数在最后
4. 循环n次

```java
public static void bubbleSort(int[] arr) {
    if (arr == null || arr.length < 2) {
       return;
    }
    for (int e = arr.length - 1; e > 0; e--) {
       for (int i = 0; i < e; i++) {
          if (arr[i] > arr[i + 1]) {
             swap(arr, i, i + 1);
          }
       }
    }
}

public static void swap(int[] arr, int i, int j) {
    arr[i] = arr[i] ^ arr[j];
    arr[j] = arr[i] ^ arr[j];
    arr[i] = arr[i] ^ arr[j];
}
```

## 异或差异

#### 注：异或运算

- **归零律 (自反性)**
  任何数与自身进行异或运算，结果都为 0。
  `a ^ a = 0`
- **恒等律**
  任何数与 0 进行异或运算，结果都为其本身。
  `a ^ 0 = a`
- **交换律**
  异或运算的顺序不影响最终结果。
  `a ^ b = b ^ a`
- **结合律**
  多个数进行异或运算时，运算的分组方式不影响结果。
  `(a ^ b) ^ c = a ^ (b ^ c)`
- **还原律 (可逆性)**
  一个数连续异或同一个数两次，结果会还原为原数。这个性质可以从 `a ^ a = 0` 和 `a ^ 0 = a` 推导出来。`a ^ b ^ b = a ^ (b ^ b) = a ^ 0 = a`

#### **不使用临时变量交换两个数**

- **原理**：利用**还原律**，通过三步操作将两个变量的值“揉”在一起再“拆”开。
- **示例**：交换变量 `a` 和 `b` 的值。
  1. `a = a ^ b` (此时 `a` 存储的是两数异或的结果)
  2. `b = a ^ b` (相当于 `(a ^ b) ^ b`，根据还原律，结果为原 `a` 的值，并赋给 `b`)
  3. `a = a ^ b` (此时 `a` 仍是 `a ^ b`，而 `b` 已是原 `a` 的值。所以这步相当于 `(a ^ b) ^ a`，根据交换律和还原律，结果为原 `b` 的值，并赋给 `a`)
     经过这三步，`a` 和 `b` 的值就成功交换了。

---



#### **查找数组中“只出现一次的数字”**

如果一个数组中，除了一个元素只出现一次，其余所有元素都出现两次，那么将数组中所有元素进行异或运算，最终结果就是那个只出现一次的数字。

- **原理**：根据**交换律**和**结合律**，我们可以将相同的数字放在一起运算。再根据**归零律** (`a ^ a = 0`)，所有出现两次的数字异或后都变为0。最后，根据**恒等律** (`0 ^ a = a`)，0与那个唯一的数字异或，结果就是它本身。
- **示例**：对于数组 `[1, 2, 1, 3, 2]`，计算 `1 ^ 2 ^ 1 ^ 3 ^ 2`。
  - 重新分组：`(1 ^ 1) ^ (2 ^ 2) ^ 3`
  - 应用归零律：`0 ^ 0 ^ 3`
  - 应用恒等律：`3`
  - 最终结果为 **3**。

---

#### **数组中只出现一次的两个数字**

**第一步：整体异或，得到两个目标数的“差异值”**

首先，将数组中所有数字进行异或运算。根据异或的性质（`a ^ a = 0`），所有出现两次的数字都会相互抵消变为0。最终，整个数组的异或结果 `xor_all` 就等于那两个只出现一次的数字（我们称之为 `a` 和 `b`）的异或值。

```
xor_all = a ^ b
```

因为 `a` 和 `b` 是两个不同的数字，所以 `xor_all` 的结果一定不为0。这意味着在 `xor_all` 的二进制表示中，至少有一位是 `1`。

**第二步：找到“差异位”，作为分组依据**

`xor_all` 中为 `1` 的位，恰恰就是 `a` 和 `b` 在该位上不同的地方（一个为0，一个为1）。我们可以利用这个“差异位”作为标准，将原数组中的所有数字分成两组。

通常，为了方便，我们会选择 `xor_all` 二进制表示中**最低位的那个 `1`**。有一个非常巧妙的位运算技巧可以快速获取这个值：

```
diff = xor_all & (-xor_all)
```

这个 `diff` 的值只有一个二进制位是 `1`，这个 `1` 就是我们用来分组的“差异位”。

**第三步：分组异或，分别求出两个数字**

现在，我们根据每个数字与 `diff` 进行按位与（`&`）运算的结果来分组：

- **第一组**：数字 `num` 满足 `(num & diff) == 0`。这意味着该数字在“差异位”上是 `0`。
- **第二组**：数字 `num` 满足 `(num & diff) != 0`。这意味着该数字在“差异位”上是 `1`。

这样分组后，会产生两个关键效果：

1. **目标数字被分离**：因为 `a` 和 `b` 在“差异位”上必然不同，所以它们会被分到不同的组里。
2. **成对数字不分离**：所有出现两次的数字，它们的值完全相同，所以在“差异位”上也一定相同，它们会一起被分到同一个组里。

最后，我们分别对这两个组内的所有数字进行异或运算。在每个组内部，成对的数字会再次相互抵消，最终每个组剩下的结果就是我们要求的 `a` 和 `b`。

```java
	public static void printOddTimesNum2(int[] arr) {
		int eO = 0, eOhasOne = 0;
		for (int curNum : arr) {
			eO ^= curNum;
		}
		int rightOne = eO & (~eO + 1);
		for (int cur : arr) {
			if ((cur & rightOne) != 0) {
				eOhasOne ^= cur;
			}
		}
		System.out.println(eOhasOne + " " + (eO ^ eOhasOne));
	}
```





## 二分

**二分查找不仅仅用于有序数组，只要你能通过中间状态判断目标值在左侧还是右侧，就可以使用二分。**

### 基本查找

```java
	public static boolean exist(int[] sortedArr, int num) {
		if (sortedArr == null || sortedArr.length == 0) {
			return false;
		}
		int L = 0;
		int R = sortedArr.length - 1;
		int mid = 0;
		while (L < R) {
			mid = L + ((R - L) >> 1);
			if (sortedArr[mid] == num) {
				return true;
			} else if (sortedArr[mid] > num) {
				R = mid - 1;
			} else {
				L = mid + 1;
			}
		}
		return sortedArr[L] == num;
	}
```

### 在arr上，找满足>=value的最左位置

```java
	public static int nearestIndex(int[] arr, int value) {
		int L = 0;
		int R = arr.length - 1;
		int index = -1;
		while (L < R) {
            // 知道L和R范围内没有数字为止，无法提前终止
			int mid = L + ((R - L) >> 1);
			if (arr[mid] >= value) {
				index = mid;
				R = mid - 1;
			} else {
				L = mid + 1;
			}
		}
		return index;
	}
```

### 局部最小

arr中，无序，相邻数字不相等，求一个局部最小（某位置数字小于两边，若在边界只考虑一边）即可，要求O(n)

```java
        public static int getLocalMinIndex(int[] arr) {
            if (arr == null || arr.length == 0) {
                return -1;
            }
            int n = arr.length;
            if (n == 1) {
                return 0;
            }
            if (arr[0] < arr[1]) {
                return 0;
            }
            if (arr[n - 1] < arr[n - 2]) {
                return n - 1;
            }
            int left = 1;
            int right = n - 2;
            while (left <= right) {
                int mid = left + ((right - left) >> 1); // 防止溢出的写法，等同于 (left + right) / 2
                if (arr[mid] < arr[mid - 1] && arr[mid] < arr[mid + 1]) {
                    return mid;
                }
                else if (arr[mid] > arr[mid - 1]) {
                    right = mid - 1;
                }
                else {
                    left = mid + 1;
                }
            }
            return -1;
        }
```

### 递归

递归求有序数列最大值

```java
        public static int getMax(int[] arr){
            return process(arr, 0, arr.length-1);
        }
        public static int process(int[] arr, int left, int right){
            if(left == right){
                return arr[left];
            }
            int mid = left + ((right - left) >> 1);
            int leftMax =process(arr, left, mid);
            int rightMax = process(arr, mid + 1, right);
            return Math.max(leftMax, rightMax);
        }
```

#### master公式

Master公式适用于符合以下标准形式的递归关系式：

```
T(n) = a * T(n/b) + O(nᵈ)
```

其中：

- **`T(n)`**: 表示处理规模为 `n` 的问题所需的时间复杂度。
- **`a`**: 表示每次递归调用产生的**子问题数量**。
- **`n/b`**: 表示每个子问题的**规模**（假设所有子问题规模相同）。
- **`O(nᵈ)`**: 表示除了递归调用本身之外，进行**问题分解和结果合并**等操作所需的时间复杂度。

**重要前提**：Master公式要求每次递归产生的子问题规模必须是一致的（即都是 `n/b`），否则无法直接应用。

通过比较 `log_b(a)`（以 `b` 为底 `a` 的对数）和 `d` 的大小关系，可以直接得出时间复杂度：

**三种情况**

| 情况  | 条件           | 时间复杂度          |
| :---- | :------------- | :------------------ |
| **1** | `log_b(a) > d` | **O(n^(log_b(a)))** |
| **2** | `log_b(a) = d` | **O(nᵈ \* log n)**  |
| **3** | `log_b(a) < d` | **O(nᵈ)**           |

简单来说，时间复杂度由 `n^(log_b(a))` 和 `nᵈ` 中增长更快的那一项决定。如果两者增长速度相同，则需要额外乘以一个 `log n` 因子。

### 归并排序

默认左边和右边都有序，合并两个有序数列，递归实现

```java
	public static void mergeSort(int[] arr) {
		if (arr == null || arr.length < 2) {
			return;
		}
		mergeSort(arr, 0, arr.length - 1);
	}

	public static void mergeSort(int[] arr, int l, int r) {
		if (l == r) {
			return;
		}
		int mid = l + ((r - l) >> 1);
		mergeSort(arr, l, mid);
		mergeSort(arr, mid + 1, r);
		merge(arr, l, mid, r);
	}

	public static void merge(int[] arr, int l, int m, int r) {
		int[] help = new int[r - l + 1];
		int i = 0;
		int p1 = l;
		int p2 = m + 1;
		while (p1 <= m && p2 <= r) {
			help[i++] = arr[p1] < arr[p2] ? arr[p1++] : arr[p2++];
		}
		while (p1 <= m) {
			help[i++] = arr[p1++];
		}
		while (p2 <= r) {
			help[i++] = arr[p2++];
		}
		for (i = 0; i < help.length; i++) {
			arr[l + i] = help[i];
		}
	}

```

#### 小和问题与逆序对问题

**小和问题**：

> 在一个数组中，每一个数左边比当前数小的数累加起来，叫做这个数组的小和。求一个数组的小和。例如：对于数组[1,3,4,2,5]
> 1左边比1小的数，没有；
> 3左边比3小的数，1；
> 4左边比4小的数，1、3；
> 2左边比2小的数，1；
> 5左边比5小的数，1、3、4、2；
> 所以小和为1+1+3+1+1+3+4+2=16

**逆序对问题**：

> 逆序对是指在一个序列中，满足 **i < j 且 a[i] > a[j]** 的有序对数量。

注意：merge时左右两边数组元素进行比较时，必须先拷贝右边

```java
	public static int smallSum(int[] arr) {
		if (arr == null || arr.length < 2) {
			return 0;
		}
		return mergeSort(arr, 0, arr.length - 1);
	}

	public static int mergeSort(int[] arr, int l, int r) {
		if (l == r) {
			return 0;
		}
		int mid = l + ((r - l) >> 1);
		return mergeSort(arr, l, mid) 
				+ mergeSort(arr, mid + 1, r) 
				+ merge(arr, l, mid, r);
	}

	public static int merge(int[] arr, int l, int m, int r) {
		int[] help = new int[r - l + 1];
		int i = 0;
		int p1 = l;
		int p2 = m + 1;
		int res = 0;
		while (p1 <= m && p2 <= r) {
			res += arr[p1] < arr[p2] ? (r - p2 + 1) * arr[p1] : 0;
			help[i++] = arr[p1] < arr[p2] ? arr[p1++] : arr[p2++];
		}
		while (p1 <= m) {
			help[i++] = arr[p1++];
		}
		while (p2 <= r) {
			help[i++] = arr[p2++];
		}
		for (i = 0; i < help.length; i++) {
			arr[l + i] = help[i];
		}
		return res;
	}
```

### 荷兰国旗问题

> 给定数组arr，将[l, r]范围内的数（当然默认是 [ 0 - arr.length - 1 ]），小于arr[r]（这里直接取数组最右边的值进行比较）放到数组左边，等于arr[r]放到数组中间，大于arr[r]放到数组右边。最后返回等于arr[r]的左, 右下标值。

```java
	public static int[] partition(int[] arr, int l, int r, int p) {
		int less = l - 1;
		int more = r + 1;
		while (l < more) {
			if (arr[l] < p) {
				swap(arr, ++less, l++);
			} else if (arr[l] > p) {
				swap(arr, --more, l);
			} else {
				l++;
			}
		}
		return new int[] { less + 1, more - 1 };
	}
```



### 快速排序

1. **选择基准（Pivot）**：从待排序的数组中选择一个元素作为“基准”。
2. **分区（Partitioning）**：重新排列数组，将所有比基准值**小**的元素放到基准的**左边**，将所有比基准值**大**的元素放到基准的**右边**。分区操作完成后，基准元素就处于其最终排序完成后的正确位置上。
3. **递归排序（Recursion）**：对基准左右两边的两个子数组，递归地重复上述两个步骤，直到子数组的大小为1或0，此时整个数组便已有序。



时间复杂度：O(n log n)

空间复杂度：O(log n)	

```java
	public static void quickSort(int[] arr) {
		if (arr == null || arr.length < 2) {
			return;
		}
		quickSort(arr, 0, arr.length - 1);
	}

	public static void quickSort(int[] arr, int l, int r) {
		if (l < r) {
			swap(arr, l + (int) (Math.random() * (r - l + 1)), r);
			int[] p = partition(arr, l, r);
			quickSort(arr, l, p[0] - 1);
			quickSort(arr, p[1] + 1, r);
		}
	}

	public static int[] partition(int[] arr, int l, int r) {
		int less = l - 1;
		int more = r;
		while (l < more) {
			if (arr[l] < arr[r]) {
				swap(arr, ++less, l++);
			} else if (arr[l] > arr[r]) {
				swap(arr, --more, l);
			} else {
				l++;
			}
		}
		swap(arr, more, r);
		return new int[] { less + 1, more };
	}
```





## 满二叉树

#### **国内定义（严格定义）**

**一棵深度为 k 且有 2^k - 1 个结点的二叉树。**
通俗来说，就是除了最后一层的叶子节点外，每一层的节点数都达到了最大值。它看起来像一个完美的三角形，所有的叶子节点都在同一层。

#### **国外定义（广义定义）**

**树中的每个节点，要么是叶子节点（没有子节点），要么恰好有两个子节点。**
这种定义下，树并不要求是“完美”的三角形，只要没有节点只有“一个”孩子即可。哈夫曼树（Huffman Tree）就是这种定义的典型例子。

###  **核心特征与性质**

基于国内定义，满二叉树具有以下鲜明的特征：

1. **叶子节点**：所有的叶子节点都在**最底层**。
2. **节点度数**：不存在度为 1 的节点（即没有节点只有一个孩子），非叶子节点的度一定为 2。
3. **节点数量**：
   - 如果层数为 `k`（根节点为第1层），则总节点数为 **2^k - 1**。
   - 第 `i` 层的节点数为 **2^(i-1)**。
   - 叶子节点的数量为 **2^(k-1)**。
4. **奇偶性**：因为节点总数是 2^k - 1，所以满二叉树的节点总数一定是**奇数**。

假设当前节点的序号为 `i`：

| 编号起始值    | 左子节点序号 | 右子节点序号 | 父节点序号      | 常见场景                  |
| :------------ | :----------- | :----------- | :-------------- | :------------------------ |
| **从 1 开始** | **2i**       | **2i + 1**   | `⌊i / 2⌋`       | 数据结构教材、算法题解    |
| **从 0 开始** | **2i + 1**   | **2i + 2**   | `⌊(i - 1) / 2⌋` | Java/C++ 数组实现、堆排序 |



## 堆排序(优先级队列)

java中的优先级队列`PriorityQueue<>`默认就是小根堆

- 空间复杂度O(1)
- 时间复杂度**O(n log n)**
- 性能非常稳定，不受输入数据初始顺序的影响。

```java
    public static void heapSort(int[] arr) {
        if (arr == null || arr.length < 2)
            return;

        for(int i = 0; i < arr.length; i++){
            heapInsert(arr, i);
        }
        int heapSize = arr.length;
        swap(arr, 0, --heapSize);
        while(heapSize > 0){
            heapify(arr, 0, heapSize);
            swap(arr, 0, --heapSize);
        }

    }

    public static void heapInsert(int[] arr, int index) {
        while (arr[index] > arr[(index - 1) / 2]) {
            swap(arr, index, (index - 1) / 2);
            index = (index - 1) / 2;
        }
    }

    public static void heapify(int[] arr, int index, int heapSize) {
        int leftChild = index * 2 + 1;
        while (leftChild < heapSize) {
            int largeIndex = leftChild + 1 < heapSize && arr[leftChild] < arr[leftChild + 1] ? leftChild+1 : leftChild;
            largeIndex = arr[index] < arr[largeIndex] ? largeIndex : index;
            if (largeIndex != index) {
                swap(arr, index, largeIndex);
                index = largeIndex;
                leftChild = index * 2 + 1;
            }
            else
                break;
        }
    }
```

- 堆扩容的代价平均是O(logn)：$扩容次数logn * 扩容容量n / 均摊n$

## 桶排序（基数排序）



```java
public static void radixSort(int[] arr) {
    radixSort(arr, 0, arr.length - 1, getMaxBit(arr));

}

public static int getMaxBit(int[] arr) {
    int max = Integer.MIN_VALUE;
    for (int i = 0; i < arr.length; i++) {
        max = max > arr[i] ? max : arr[i];
    }
    int count = 0;
    while (max > 0) {
        max /= 10;
        count++;
    }
    return count;
}

public static void radixSort(int[] arr, int begin, int end, int maxBit) {
    int radix = 10;
    int[] bucket = new int[end - begin + 1];
    int i = 0, j = 0;
    for (int d = 1; d <= maxBit; d++) {
        int[] count = new int[radix];
        for (i = begin; i <= end; i++) {
            j = getDigit(arr[i], d);
            count[j]++;
        }
        for (i = 1; i < radix; i++)
            count[i] = count[i] + count[i - 1];
        for (i = end; i >= begin; i--) {
            j = getDigit(arr[i], d);
            bucket[count[j] - 1] = arr[i];
            count[j]--;
        }
        for (i = 0; i < bucket.length; i++)
            arr[begin + i] = bucket[i];
    }


}

public static int getDigit(int x, int d) {
    return ((x / ((int) Math.pow(10, d - 1))) % 10);
}
```

4. **数据量很小（< 50）**：直接用 **插入排序**。
5. **数据基本有序**：首选 **插入排序**。
6. **整数排序且范围不大**：首选 **计数排序**。

## 反转链表

### **方法一：迭代法（双指针 / 三指针）**

这是**最推荐**的方法，因为它空间复杂度为 O(1)，且逻辑直观，不容易出错。

**核心思路：**
我们需要三个指针：

1. `prev`（前驱节点）：初始为 `null`，因为反转后原头节点将变为尾节点，指向 `null`。
2. `curr`（当前节点）：初始为 `head`，用于遍历链表。
3. `nextTemp`（临时节点）：用于暂存 `curr` 的下一个节点，防止断链。

**步骤拆解：**

1. **存后继**：先用 `nextTemp` 保存 `curr.next`。
2. **反转指向**：将 `curr.next` 指向 `prev`。
3. **移动指针**：`prev` 和 `curr` 都向后移动一步（`prev` 移到 `curr`，`curr` 移到 `nextTemp`）。

**代码实现：**

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;       // 1. 初始化前驱为 null
        ListNode curr = head;       // 2. 初始化当前节点为头节点
        
        while (curr != null) {
            ListNode nextTemp = curr.next; // 3. 【关键】暂存后继节点，防止断链
            curr.next = prev;              // 4. 反转指针：当前节点指向前驱
            prev = curr;                   // 5. 前驱指针后移
            curr = nextTemp;               // 6. 当前指针后移
        }
        
        return prev; // 7. 循环结束时，curr 为 null，prev 指向新的头节点
    }
}
```

### **方法二：递归法**

递归法代码更简洁，但理解起来稍微抽象一些，且空间复杂度为 O(n)（因为递归调用栈）。

**核心思路：**

1. **终止条件**：如果当前节点是 `null` 或只有一个节点，直接返回。
2. **递归**：假设后面的节点都已经反转好了。
3. **反转**：将当前节点的下一个节点的 `next` 指向当前节点（`head.next.next = head`），并将当前节点的 `next` 置为 `null`（防止成环）。

**代码实现：**

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        // 1. 递归终止条件：空链表或只有一个节点
        if (head == null || head.next == null) {
            return head;
        }
        // 2. 递归反转后续节点，newHead 是原链表的最后一个节点（即新头节点）
        ListNode newHead = reverseList(head.next);
        // 3. 【关键】反转当前层：让下一个节点指向自己
        head.next.next = head;
        // 4. 断开原来的指向，防止成环
        head.next = null;
        return newHead;
    }
}
```

## 判断链表回文

### **方法一：快慢指针 + 反转链表（最优解）**

**空间复杂度为 O(1)** 的最佳方案。
**核心思路**：找到链表中点 -> 反转后半部分 -> 对比前后两部分。

 **步骤详解**

1. **找中点**：使用快慢指针。快指针 `fast` 每次走两步，慢指针 `slow` 每次走一步。当 `fast` 到达末尾时，`slow` 刚好在中间。
2. **反转后半段**：从 `slow` 的下一个节点开始，反转后半部分链表。
3. **对比**：一个指针从头开始，一个指针从反转后的后半段头部开始，逐个比较值是否相等。

```java
class Solution {
    public boolean isPalindrome(ListNode head) {
        if (head == null || head.next == null) return true;

        // 1. 快慢指针找中点
        ListNode slow = head;
        ListNode fast = head;
        while (fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        // 2. 反转后半部分链表
        // slow 是中点，slow.next 是后半部分的起点
        ListNode secondHalfHead = reverseList(slow.next);

        // 3. 对比前后两部分
        ListNode p1 = head;
        ListNode p2 = secondHalfHead;
        boolean isPalindrome = true;
        
        while (p2 != null) { // 只需要遍历后半部分
            if (p1.val != p2.val) {
                isPalindrome = false;
                break;
            }
            p1 = p1.next;
            p2 = p2.next;
        }

        // 4. (可选) 恢复链表结构
        // 面试中如果要求严格，需要把反转的后半部分再反转回去
        slow.next = reverseList(secondHalfHead);

        return isPalindrome;
    }

    // 辅助函数：反转链表
    private ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode curr = head;
        while (curr != null) {
            ListNode nextTemp = curr.next;
            curr.next = prev;
            prev = curr;
            curr = nextTemp;
        }
        return prev;
    }
}
```

1. **奇偶数长度处理**：
   - 在快慢指针找中点时，如果链表长度是奇数（如 `1->2->3->2->1`），`slow` 会停在中间的 `3`。此时反转 `slow.next`（即 `2->1`）是正确的，比较时中间的 `3` 会被自动忽略，不影响结果。
2. **恢复链表**：
   - 在工程实践中，修改数据结构是大忌。如果面试官问起，一定要提到在比较结束后，**需要将后半部分链表再次反转并接回原处**，以保持链表原样。
3. **边界条件**：
   - 空链表（`head == null`）或只有一个节点（`head.next == null`）时，应直接返回 `true`。



### **方法二：数组 + 双指针（最直观）**

如果你不想处理复杂的指针操作，可以将链表值复制到数组中，利用数组随机访问的特性来判断。

**思路**：

1. 遍历链表，将所有节点的值存入 `ArrayList` 或数组。
2. 使用双指针，一个指向数组头部，一个指向尾部，向中间移动并比较。



### **方法三：栈（辅助法）**

利用栈“先进后出”的特性，可以实现逆序比较。

**思路**：

1. 遍历链表，将所有节点压入栈中。
2. 再次遍历链表，同时从栈中弹出节点，比较当前节点和弹出节点的值。

> **注意**：这种方法空间复杂度是 O(n)，不如方法一优秀，但逻辑也很清晰。

## 按值划分链表

将单链表按某一个值划分成左边小、中间相等、右边打的形式

【题目】：给定一个单链表头结点head，节点的值类型是整数，在给定一个整数pivot。实现一份调整链表的函数，将链表调整为左部分的值小于pivot，中间等于，右边大于。

### 方法一：数组法

1. 将链表值复制到数组中
2. 在数组上做partition
3. 还原为链表



### 方法二：**六指针法**

我们将原链表拆分成三个独立的子链表，分别存放“小于”、“等于”和“大于” pivot 的节点，最后再将它们拼接起来。

我们需要维护 **6个指针**（3个头，3个尾）：

1. **小于区 (Less)**：`sH` (头), `sT` (尾)
2. **等于区 (Equal)**：`eH` (头), `eT` (尾)
3. **大于区 (Big)**：`bH` (头), `bT` (尾)

**步骤：**

1. **遍历**：遍历原链表，把当前节点从原链表摘下来（断开 `next` 指针）。
2. **分发**：根据节点值与 `pivot` 的比较结果，将其挂到对应区域的尾部。
3. **拼接**：遍历结束后，按照 `Less -> Equal -> Big` 的顺序将三个链表首尾相连。



```java
    /**
     * 将链表划分为 小 -> 等 -> 大 三部分
     * 时间复杂度: O(N)
     * 空间复杂度: O(1)
     */
    public static Node listPartition(Node head, int pivot) {
        // 1. 初始化六个指针
        Node sH = null; // 小于区头
        Node sT = null; // 小于区尾
        Node eH = null; // 等于区头
        Node eT = null; // 等于区尾
        Node bH = null; // 大于区头
        Node bT = null; // 大于区尾
        
        Node next = null; // 用于暂存下一个节点，防止断链
        
        // 2. 遍历原链表，进行分发
        while (head != null) {
            next = head.next; // 保存下一个节点
            head.next = null; // 【关键】断开当前节点的next，防止引用混乱
            
            if (head.value < pivot) {
                // --- 放入小于区 ---
                if (sH == null) {
                    // 如果是第一个进入小于区的节点，头尾都指向它
                    sH = head;
                    sT = head;
                } else {
                    // 否则挂在尾部，并更新尾指针
                    sT.next = head;
                    sT = head;
                }
            } else if (head.value == pivot) {
                // --- 放入等于区 ---
                if (eH == null) {
                    eH = head;
                    eT = head;
                } else {
                    eT.next = head;
                    eT = head;
                }
            } else {
                // --- 放入大于区 ---
                if (bH == null) {
                    bH = head;
                    bT = head;
                } else {
                    bT.next = head;
                    bT = head;
                }
            }
            head = next; // 移动到原链表的下一个节点
        }
        
        // 3. 拼接三个区域
        // 3.1 连接 小于区 和 等于区
        if (sT != null) {
            sT.next = eH;
            // 如果等于区为空，更新等于区的尾指针为小于区的尾，方便后续连接
            eT = (eT == null) ? sT : eT;
        }
        
        // 3.2 连接 等于区 和 大于区
        if (eT != null) {
            eT.next = bH;
        }
        
        // 4. 返回新的头结点
        // 优先返回小于区的头，如果没有则返回等于区的头，最后才是大于区的头
        return (sH != null) ? sH : (eH != null) ? eH : bH;
    }
```

### 方法一 利用哈希表



整个过程只需要**两次遍历**：

1. **第一次遍历（构建映射）**：
   - 遍历原链表，为每个原节点创建一个新节点（只复制 `value`）。
   - 将 `<原节点, 新节点>` 的对应关系存入哈希表。
2. **第二次遍历（连接指针）**：
   - 再次遍历原链表。
   - 对于每个节点，通过哈希表找到对应的新节点。
   - 设置新节点的 `next` 和 `rand` 指针：
     - 新节点的 `next` = 哈希表中 `原节点.next` 对应的新节点。
     - 新节点的 `rand` = 哈希表中 `原节点.rand` 对应的新节点。

```java
    /**
     * 使用哈希表复制带随机指针的链表
     * 时间复杂度: O(N) - 遍历两次
     * 空间复杂度: O(N) - 哈希表存储 N 个节点
     */
    public static Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }

        // 1. 创建哈希表，存储 <原节点, 新节点> 的映射
        Map<Node, Node> map = new HashMap<>();

        // 2. 第一次遍历：复制所有节点并存入哈希表
        Node cur = head;
        while (cur != null) {
            map.put(cur, new Node(cur.value));
            cur = cur.next;
        }

        // 3. 第二次遍历：设置新节点的 next 和 rand 指针
        cur = head;
        while (cur != null) {
            // 从哈希表中取出当前原节点对应的新节点
            Node cloneNode = map.get(cur);
            
            // 设置 next 指针：
            // 原节点的 next 是 cur.next，对应的新节点就是 map.get(cur.next)
            cloneNode.next = map.get(cur.next);
            
            // 设置 rand 指针：
            // 原节点的 rand 是 cur.rand，对应的新节点就是 map.get(cur.rand)
            cloneNode.rand = map.get(cur.rand);
            
            cur = cur.next;
        }
```





### 方法二 **原地复制法（三步走）**

为了满足 O(1) 的空间复杂度，我们不能开辟额外的哈希表。核心技巧是利用原链表的 `next` 指针来建立原节点和复制节点之间的映射关系。

整个过程分为三步：

1. **复制并插入**：遍历原链表，将每个节点复制一份，并插入到原节点的后面。
   - 原链表：`A -> B -> C -> null`
   - 操作后：`A -> A' -> B -> B' -> C -> C' -> null`
2. **设置随机指针**：再次遍历这个“加长”的链表，设置复制节点（A', B', C'）的 `rand` 指针。
   - 关键逻辑：如果原节点 `A` 的 `rand` 指向 `C`，那么复制节点 `A'` 的 `rand` 就应该指向 `C` 的下一个节点（即 `C'`）。
   - 公式：`cur.next.rand = cur.rand.next`
3. **拆分链表**：第三次遍历，将交织在一起的原链表和复制链表分离，恢复原链表，并提取出复制链表。

```java
    /**
     * 复制带随机指针的链表
     * 时间复杂度: O(N) - 遍历三次
     * 空间复杂度: O(1) - 只使用了几个指针变量
     */
    public static Node copyRandomList(Node head) {
        if (head == null) {
            return null;
        }

        // --- 第一步：复制节点并插入到原节点之后 ---
        // 将 A->B->C 变为 A->A'->B->B'->C->C'
        Node cur = head;
        Node next = null;
        while (cur != null) {
            next = cur.next; // 1. 暂存原链表的下一个节点
            
            // 2. 创建复制节点，插入到 cur 和 next 之间
            cur.next = new Node(cur.value); 
            cur.next.next = next;
            
            cur = next; // 3. 移动到下一个原节点
        }

        // --- 第二步：设置复制节点的 rand 指针 ---
        cur = head;
        Node copy = null;
        while (cur != null) {
            next = cur.next.next; // 1. 暂存下一个原节点
            copy = cur.next;      // 2. 当前复制节点
            
            // 3. 设置随机指针
            // 如果 cur.rand 不为空，则 copy.rand 指向 cur.rand 的下一个节点（即对应的复制节点）
            copy.rand = (cur.rand != null) ? cur.rand.next : null;
            
            cur = next; // 4. 移动到下一个原节点
        }

        // --- 第三步：拆分链表 ---
        // 恢复原链表，提取复制链表
        Node res = head.next; // 复制链表的头结点
        cur = head;
        while (cur != null) {
            next = cur.next.next; // 1. 暂存下一个原节点
            
            // 2. 分离原链表
            cur.next = next;
            
            // 3. 分离复制链表
            // 如果 next 不为空，则 copy.next 指向 next 的下一个节点（即下一个复制节点）
            copy = cur.next; // 注意：这里 cur.next 已经是新的 cur 了，逻辑上对应上面的 copy 变量
            // 修正逻辑：我们需要用之前的 copy 引用，或者重新获取
            // 让我们重新梳理一下拆分循环的变量
            
            // 重新定义拆分逻辑，保持清晰
            break; 
        }
        
        // 重新写拆分部分，避免变量混淆
        cur = head;
        while (cur != null) {
            Node clone = cur.next;      // 当前复制节点
            next = clone.next;          // 下一个原节点
            
            // 连接原链表：cur -> next
            cur.next = next;
            
            // 连接复制链表：clone -> (next != null ? next.next : null)
            clone.next = (next != null) ? next.next : null;
            
            // 移动指针
            cur = next;
        }

        return res;
    }
```



## 判断环

### **方法一 快慢指针法（最优解）**

时间复杂度

这种方法的核心思想非常直观：想象两个人在环形跑道上跑步，一个跑得快，一个跑得慢。如果跑道是环形的，快的人最终一定会追上慢的人；如果跑道是直的，快的人会先到达终点。

#### **核心思路**

1. **定义两个指针**：
   - **慢指针 (`slow`)**：每次移动 **1** 步。
   - **快指针 (`fast`)**：每次移动 **2** 步。
2. **同时出发**：两个指针都从链表的头节点 `head` 开始。
3. **判断相遇**：
   - **有环**：如果链表中存在环，快指针最终会在环内追上并相遇慢指针（`fast == slow`）。
   - **无环**：如果链表中没有环，快指针会先到达链表的末尾（`fast` 或 `fast.next` 变为 `null`）。

```java
   /**
     * 判断链表是否有环
     * 时间复杂度: O(N)
     * 空间复杂度: O(1)
     */
    public boolean hasCycle(ListNode head) {
        // 边界条件：空链表或只有一个节点，必定无环
        if (head == null || head.next == null) {
            return false;
        }

        // 1. 初始化快慢指针
        ListNode slow = head;
        ListNode fast = head;

        // 2. 遍历链表
        // 注意循环条件：必须同时检查 fast 和 fast.next 是否为 null
        // 防止 fast.next.next 出现空指针异常
        while (fast != null && fast.next != null) {
            slow = slow.next;           // 慢指针走一步
            fast = fast.next.next;      // 快指针走两步

            // 3. 判断是否相遇
            if (slow == fast) {
                return true; // 相遇，说明有环
            }
        }

        // 快指针到达末尾，说明无环
        return false;
    }
```

#### 补充

当快慢指针相遇后，快指针回到头结点，快慢指针再次开始每次都走1步，一定会在入环节点相遇

**核心思路（数学原理）：**

- 快指针速度是慢指针的2倍，如果有环，它们一定会在环内相遇。
- 设头节点到环入口距离为 `a`，环入口到相遇点距离为 `b`，相遇点到环入口距离为 `c`。
- 快指针路程：`a + n(b+c) + b`，慢指针路程：`a + b`。
- 因为快指针路程是慢指针的2倍，化简得 `a = c + (n-1)(b+c)`。
- 这意味着：**从头节点出发的指针**和**从相遇点出发的指针**，以相同速度移动，最终会在环入口相遇。



### 方法二：哈希表法

#### **核心思路**

1. 遍历链表，将访问过的每个节点都存入一个哈希集合（`HashSet`）中。
2. 每访问一个新节点，先检查它是否已经存在于集合中。
3. **有环**：如果当前节点已经在集合中出现过，说明之前访问过它，链表存在环。
4. **无环**：如果遍历到 `null` 都没有发现重复节点，说明无环。

```java
    /**
     * 使用哈希表判断链表是否有环
     * 时间复杂度: O(N)
     * 空间复杂度: O(N)
     */
    public boolean hasCycle(ListNode head) {
        Set<ListNode> visited = new HashSet<>();
        ListNode current = head;

        while (current != null) {
            // 如果节点已存在，说明有环
            if (visited.contains(current)) {
                return true;
            }
            // 将当前节点加入集合
            visited.add(current);
            current = current.next;
        }

        return false;
    }
```



| 方法       | 时间复杂度 | 空间复杂度 | 优点                   | 缺点                         |
| ---------- | ---------- | ---------- | ---------------------- | ---------------------------- |
| 快慢指针法 | O(N)       | O(1)       | 性能最优，空间效率最高 | 逻辑稍抽象，需注意循环条件   |
| 哈希表法   | O(N)       | O(N)       | 逻辑最简单，不易出错   | 需要额外的 O(N) 空间存储节点 |

```java
	public static Node getIntersectNode(Node head1, Node head2) {
		if (head1 == null || head2 == null) {
			return null;
		}
		Node loop1 = getLoopNode(head1);
		Node loop2 = getLoopNode(head2);
		if (loop1 == null && loop2 == null) {
			return noLoop(head1, head2);
		}
		if (loop1 != null && loop2 != null) {
			return bothLoop(head1, loop1, head2, loop2);
		}
		return null;

	// 快慢指针（Floyd判圈算法）
	public static Node getLoopNode(Node head) {
		if (head == null || head.next == null || head.next.next == null) {
			return null;
		}
		Node n1 = head.next; // n1 -> slow
		Node n2 = head.next.next; // n2 -> fast
		while (n1 != n2) {
			if (n2.next == null || n2.next.next == null) {
				return null;
			}
			n2 = n2.next.next;
			n1 = n1.next;
		}
		n2 = head; // n2 -> walk again from head
		while (n1 != n2) {
			n1 = n1.next;
			n2 = n2.next;
		}
		return n1;
	}

	public static Node noLoop(Node head1, Node head2) {
		if (head1 == null || head2 == null) {
			return null;
		}
		Node cur1 = head1;
		Node cur2 = head2;
		int n = 0;
		while (cur1.next != null) {
			n++;
			cur1 = cur1.next;
		}
		while (cur2.next != null) {
			n--;
			cur2 = cur2.next;
		}
		if (cur1 != cur2) {
			return null;
		}
		cur1 = n > 0 ? head1 : head2;
		cur2 = cur1 == head1 ? head2 : head1;
		n = Math.abs(n);
		while (n != 0) {
			n--;
			cur1 = cur1.next;
		}
		while (cur1 != cur2) {
			cur1 = cur1.next;
			cur2 = cur2.next;
		}
		return cur1;
	}

	public static Node bothLoop(Node head1, Node loop1, Node head2, Node loop2) {
		Node cur1 = null;
		Node cur2 = null;
		if (loop1 == loop2) {
			cur1 = head1;
			cur2 = head2;
			int n = 0;
			while (cur1 != loop1) {
				n++;
				cur1 = cur1.next;
			}
			while (cur2 != loop2) {
				n--;
				cur2 = cur2.next;
			}
			cur1 = n > 0 ? head1 : head2;
			cur2 = cur1 == head1 ? head2 : head1;
			n = Math.abs(n);
			while (n != 0) {
				n--;
				cur1 = cur1.next;
			}
			while (cur1 != cur2) {
				cur1 = cur1.next;
				cur2 = cur2.next;
			}
			return cur1;
		} else {
			cur1 = loop1.next;
			while (cur1 != loop1) {
				if (cur1 == loop2) {
					return loop1;
				}
				cur1 = cur1.next;
			}
			return null;
		}
	}
```

## **三种遍历方式详解**

二叉树的三种核心遍历方法是 **前序遍历**、**中序遍历** 和 **后序遍历**。它们的名称来源于**根节点**被访问的先后顺序。

这三种遍历都遵循一个共同的模式：先遍历左子树，再遍历右子树。唯一的区别在于**访问根节点的时机**。

为了便于理解，我们以这棵二叉树为例：

```txt
    1
   / \
  2   3
 / \   \
4   5   6
```

#### **1. 前序遍历 (Pre-order Traversal)**

- **核心规则**：**根节点 → 左子树 → 右子树**
- **记忆口诀**：**根左右**
- **遍历过程**：
  1. 访问根节点 `1`。
  2. 前序遍历左子树（以 `2` 为根）：访问 `2`，然后是 `2` 的左子节点 `4`，再是 `2` 的右子节点 `5`。
  3. 前序遍历右子树（以 `3` 为根）：访问 `3`，然后是 `3` 的右子节点 `6`。
- **遍历结果**：`1 → 2 → 4 → 5 → 3 → 6`

#### **2. 中序遍历 (In-order Traversal)**

- **核心规则**：**左子树 → 根节点 → 右子树**
- **记忆口诀**：**左根右**
- **遍历过程**：
  1. 中序遍历左子树（以 `2` 为根）：先访问 `2` 的左子节点 `4`，然后是根 `2`，最后是 `2` 的右子节点 `5`。
  2. 访问根节点 `1`。
  3. 中序遍历右子树（以 `3` 为根）：先访问根 `3`，然后是 `3` 的右子节点 `6`。
- **遍历结果**：`4 → 2 → 5 → 1 → 3 → 6`

#### **3. 后序遍历 (Post-order Traversal)**

- **核心规则**：**左子树 → 右子树 → 根节点**
- **记忆口诀**：**左右根**
- **遍历过程**：
  1. 后序遍历左子树（以 `2` 为根）：先访问 `2` 的左子节点 `4`，再访问 `2` 的右子节点 `5`，最后是根 `2`。
  2. 后序遍历右子树（以 `3` 为根）：先访问 `3` 的右子节点 `6`，然后是根 `3`。
  3. 访问根节点 `1`。
- **遍历结果**：`4 → 5 → 2 → 6 → 3 → 1`

```java
 public List<Integer> preorderTraversalIterative(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;

        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);

 public List<Integer> inorderTraversalIterative(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Stack<TreeNode> stack = new Stack<>();
        TreeNode curr = root;

        while (curr != null || !stack.isEmpty()) {
            // 一路向左，把路径上的节点都压入栈
            while (curr != null) {
                stack.push(curr);
                curr = curr.left;
            }
            // 弹出栈顶（最左节点），访问它
            curr = stack.pop();
            res.add(curr.val);
            // 转向右子树
            curr = curr.right;
        }
        return res;

    public List<Integer> postorderTraversalIterative(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        if (root == null) return res;

        Stack<TreeNode> stack1 = new Stack<>();
        Stack<TreeNode> stack2 = new Stack<>();
        
        stack1.push(root);
        
        // 栈1用于处理：根->右->左
        while (!stack1.isEmpty()) {
            TreeNode node = stack1.pop();
            stack2.push(node); // 压入栈2（逆序）
            
            if (node.left != null) stack1.push(node.left);
            if (node.right != null) stack1.push(node.right);
        }
        
        // 栈2弹出顺序即为：左->右->根
        while (!stack2.isEmpty()) {
            res.add(stack2.pop().val);
        }
        return res;
    }


    public List<List<Integer>> levelOrder(TreeNode root) {
        List<List<Integer>> result = new ArrayList<>();
        if (root == null) return result;

        // java中队列就是链表
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        while (!queue.isEmpty()) {
            int levelSize = queue.size(); // 当前层的节点数量
            List<Integer> currentLevel = new ArrayList<>();

            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
                currentLevel.add(node.val);   // 遍历的节点操作

                // 将下一层的节点加入队列
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            result.add(currentLevel);
        }
        return result;
    }
```

### 非递归解释

#### 前序遍历

**顺序：根 -> 左 -> 右**

前序遍历的非递归实现是三种遍历中最简单的。因为根节点是第一个被访问的，所以我们在把节点压入栈的同时，就可以直接把它加入结果集。

**核心逻辑：**

1. 将根节点压入栈。
2. 弹出栈顶节点，**立刻访问（加入结果集）**。
3. 因为栈是“后进先出”的，为了保证下一次弹出的是左子节点，我们必须**先压入右子节点，再压入左子节点**。



#### 后序遍历

后序遍历的顺序是：`左子树 -> 右子树 -> 根节点`。
如果我们把这个顺序完全**反转**过来，就变成了：`根节点 -> 右子树 -> 左子树`。

你发现了吗？这个反转后的顺序，其实就是一个**“先访问根，然后先走右边，再走左边”**的特殊前序遍历！

所以，我们的非递归实现可以拆解为两步：

1. **正向收集**：用栈模拟前序遍历，但是**先压左子节点，再压右子节点**（这样出栈时就是先右后左），把访问到的节点按 `根 -> 右 -> 左` 的顺序存入一个结果集。
2. **反转结果**：最后将结果集反转，就得到了完美的 `左 -> 右 -> 根` 后序遍历。

所以可以使用双栈实现



#### 中序遍历

**顺序：左 -> 根 -> 右**

中序遍历不能像前序那样简单地把根节点压栈就访问，因为我们必须先处理完所有的左子树。

**核心逻辑（左到底，弹出记，右转走）：**

1. 从当前节点开始，**不断向左走**，把沿途经过的所有节点都压入栈中，直到左边走不通（遇到 `null`）。
2. 弹出栈顶节点（此时它就是当前最小的左节点），**访问它**。
3. 将当前指针转向该节点的**右子树**，然后重复步骤1。



## 二叉树宽度



求二叉树的宽度，最经典且直观的方法就是利用**层序遍历（BFS）**。

简单来说，二叉树的宽度就是**所有层级中，节点数量最多的那一层的节点数**。我们可以借助一个队列（Queue），像剥洋葱一样一层一层地遍历二叉树，每遍历到新的一层，就数数这一层有多少个节点，并实时更新最大宽度。

```java
    public static int levelOrder(TreeNode root) {
        if (root == null) return 0;
        // java中队列就是链表
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);

        int curLevel = 0;
        int maxWidthLevel = 0;
        int maxWidth = Integer.MIN_VALUE;

        while (!queue.isEmpty()) {
            curLevel++;
            int levelSize = queue.size(); // 当前层的节点数量
            maxWidth = maxWidth > levelSize ? maxWidth : levelSize;
            maxWidthLevel = maxWidth > levelSize ? maxWidthLevel : curLevel;
            for (int i = 0; i < levelSize; i++) {
                TreeNode node = queue.poll();
//                print(node);
                // 将下一层的节点加入队列
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
        }
        return maxWidth;
    }

			node = queue.poll();
			left = node.left;
			right = node.right;
			if (left != null) {
				levelMap.put(left, levelMap.get(node) + 1);
				queue.add(left);
			}
			if (right != null) {
				levelMap.put(right, levelMap.get(node) + 1);
				queue.add(right);
			}
			if (levelMap.get(node) > curLevel) {
				curWidth = 1;
				curLevel = levelMap.get(node);
			} else {
				curWidth++;
			}
			maxWidth = Math.max(maxWidth, curWidth);
		}
		return maxWidth;
	}
```

## 判断完全二叉树

 **核心原理：空节点守门人**

完全二叉树的定义是：除了最后一层外，其余各层都是满的，且最后一层的节点都**连续靠左**排列。

基于这个特性，我们可以得出一个非常巧妙的判断规则：
在进行层序遍历时，**一旦遇到了第一个“空节点（null）”，那么这棵树后续的所有节点都必须为空。** 如果在遇到空节点之后，又出现了一个非空节点，就说明节点没有连续靠左，它就不是一棵完全二叉树。

```java
    public static boolean isCompleteTree(TreeNode root){
        if (root == null)
            return true;
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer( root);
        boolean leaf = false;
        while(!queue.isEmpty()){
            root = queue.poll();
            if(root == null)
                leaf = true;
            else{
                if(leaf)
                    return false;
                queue.offer(root.left);
                queue.offer(root.right);
            }
        }
        return true;
    }
```

### 二叉树高度

求二叉树的高度（或深度），最经典且优雅的方法是使用**递归（DFS）**。

它的核心逻辑非常简单：**一棵树的高度 = 它的左子树和右子树中，较高的那个高度 + 1（加上根节点本身的高度）**。

```java
    public static int getTreeHeight(TreeNode root){
        // 1. 递归终止条件：如果节点为空，高度为 0
        if(root ==null)
            return 0;
        // 2. 分别递归求出左子树和右子树的高度
        int leftHeight = getTreeHeight(root.left);
        int rightHeight = getTreeHeight(root.right);
        // 3. 取两者中的较大值，并加上当前根节点的高度 1
        return Math.max(leftHeight, rightHeight) + 1;
    }
```

```java
        int max;

            this.max = max;

    public static ReturnData process(TreeNode root) {
        // base case 递归出口
        if (root == null)
            return null;
		// 默认得到左右树的信息
        ReturnData leftData = process(root.left);
        ReturnData rightData = process(root.right);

        // 处理得到的左右树信息
        boolean isBST = true;
        int min = root.value;
        int max = root.value;

        if(leftData != null && rightData == null){
            isBST = leftData.isBST && leftData.max < root.value;
            max = Math.max(max, leftData.max);
            min = Math.min(min, leftData.min);
        }
        if(leftData == null && rightData != null){
            isBST = rightData.isBST && rightData.min > root.value;
            max = Math.max(max, rightData.max);
            min = Math.min(min, rightData.min);
        }
        if(leftData != null && rightData != null){
            isBST = leftData.isBST && rightData.isBST && leftData.max < root.value && rightData.min > root.value;
            max = Math.max(max, leftData.max);
            max = Math.max(max, rightData.max);
            min = Math.min(min, leftData.min);
            min = Math.min(min, rightData.min);
        }
        return new ReturnData(isBST, max, min);
    }
```

## 最低共同祖先

**问题**：给定二叉树节点node1和node2， 找到他们的最低共同祖先。

解决这道题最优雅且高效的方法是使用**递归（后序遍历）**。

 **核心思路：自底向上汇报**

我们可以把递归的过程想象成每个节点在向它的父节点“汇报”：

1. 如果当前节点是 `null`，说明这条路走不通，汇报 `null`。
2. 如果当前节点正好是 `node1` 或 `node2` 中的一个，说明找到了目标，把自己汇报上去。
3. 当前节点会分别去左子树和右子树打听消息（递归调用）。
   - **情况一（左右开弓）**：如果左子树和右子树都带回了非空的结果，说明 `node1` 和 `node2` 分别藏在当前节点的左右两边。那么，**当前节点就是它们的最低公共祖先**。
   - **情况二（单线传递）**：如果只有一边带回了非空结果，另一边是 `null`，说明两个目标节点都藏在那一边。那么，就把那个非空的结果继续往上汇报。

```java
    public static TreeNode lowestCommonAncestor(TreeNode root, TreeNode o1, TreeNode o2){
        if(root == null || root == o1 || root == o2)
            return root;
        TreeNode left = lowestCommonAncestor(root.left, o1, o2);
        TreeNode right = lowestCommonAncestor(root.right, o1, o2);
        if(left != null && right != null)
            return root;
        if(left != null)
            return left;
        if(right != null)
            return right;
        return null;
    }
```

## 二叉树序列化和反序列化

二叉树的**序列化**和**反序列化**，其实就是把内存中那棵立体的树，变成一串能存进文件或通过网络传输的字符串（序列化）；然后再把这串字符串完美还原成原来那棵树的过程（反序列化）。

因为二叉树在内存里是依靠指针（左右孩子的引用）连在一起的，一旦程序关闭，这些指针关系就没了。所以我们需要用一种特定的规则（比如前序遍历），把树的结构和节点的值“拍扁”存起来。

最经典且好写的方案是使用**带空指针标记的前序遍历**。也可以有其他遍历的序列化



**中序遍历的序列化是无法唯一还原（反序列化）出一棵二叉树的！**（因为中序遍历无法确定根节点的位置，`[null, 1, null, 2, null]` 既可以是 1 为根右孩子是 2，也可以是 2 为根左孩子是 1）。

所以，中序遍历通常只能写出“序列化”的代码，而**后序遍历**则和前序一样，可以完美实现“序列化 + 反序列化”。


```java
public String serializePostorder(TreeNode root) {
    if (root == null) {
        return "#,";
    }
    String res = "";
    res += serializePostorder(root.left);   // 1. 先序列化左子树
    res += serializePostorder(root.right);  // 2. 再序列化右子树
    res += root.value + ",";                // 3. 最后记录根节点
    return res;
}

// 后序遍历反序列化
public TreeNode deserializePostorder(String data) {
    // 将字符串分割并放入双向队列（当作栈来用，从尾部取数据）
    LinkedList<String> stack = new LinkedList<>(Arrays.asList(data.split(",")));
    return deserializePostHelper(stack);
}

private TreeNode deserializePostHelper(LinkedList<String> stack) {
    // 从尾部弹出一个值（因为后序遍历的根在最后）
    String value = stack.pollLast(); 
    
    if (value.equals("#")) {
        return null;
    }
    
    // 1. 建立当前根节点
    TreeNode node = new TreeNode(Integer.parseInt(value));
    // 2. 注意！后序遍历还原时，要先递归构建右子树，再构建左子树
    // （因为字符串是从后往前读的：根 -> 右 -> 左）
    node.right = deserializePostHelper(stack);
    node.left = deserializePostHelper(stack);
    
    return node;
}
```

```java
// 序列化：把二叉树变成字符串（层序遍历）
public String serializeLevel(TreeNode root) {
    if (root == null) {
        return "";
    }
    
    StringBuilder res = new StringBuilder();
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        
        if (node == null) {
            // 遇到空节点，拼接 "#"
            res.append("#,");
        } else {
            // 遇到非空节点，拼接值，并将其左右孩子（即使是null）入队
            res.append(node.value).append(",");
            queue.offer(node.left);
            queue.offer(node.right);
        }
    }
    return res.toString();
}

// 反序列化：把字符串还原成二叉树（层序遍历）
public TreeNode deserializeLevel(String data) {
    if (data == null || data.isEmpty()) {
        return null;
    }
    
    // 把字符串按逗号切分成数组
    String[] values = data.split(",");
    
    // 创建根节点
    TreeNode root = new TreeNode(Integer.parseInt(values[0]));
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    
    // 使用一个索引 i 来遍历 values 数组，为队列中的节点分配左右孩子
    int i = 1; 
    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();
        
        // 1. 处理左孩子
        if (!values[i].equals("#")) {
            node.left = new TreeNode(Integer.parseInt(values[i]));
            queue.offer(node.left);
        }
        i++; // 无论是不是 "#"，索引都要往后移
        
        // 2. 处理右孩子
        if (!values[i].equals("#")) {
            node.right = new TreeNode(Integer.parseInt(values[i]));
            queue.offer(node.right);
        }
        i++; // 索引继续往后移
    }
    
    return root;
}
```

## 最小生成树MST

最小生成树（MST）算法主要用于解决**带权无向连通图**中的经典问题：如何选出几条边，把所有节点都连接起来，并且保证这些边的**总权重最小**。

最常用的两种算法分别是 **Kruskal（克鲁斯卡尔）算法** 和 **Prim（普里姆）算法**。结合你提供的 `Graph`、`Node` 和 `Edge` 结构，我为你详细讲解这两种算法的逻辑与代码实现。

### **1. Kruskal 算法（克鲁斯卡尔）**

**核心思想：**
“**只看边，不看点**”。把所有边按权重从小到大排序，然后从小到大依次挑选。只要这条边连接的两个节点**不在同一个连通分量里**（即不会形成环），就把它选进最小生成树。

**关键点：** 判断两个节点是否连通，需要用到**并查集（Union-Find）**数据结构。

```java
import java.util.*;

public class KruskalMST {

    // 并查集类：用于快速判断两个节点是否已经连通
    static class UnionFind {
        private HashMap<Node, Node> parent;
        private HashMap<Node, Integer> size;

        public UnionFind(Collection<Node> nodes) {
            parent = new HashMap<>();
            size = new HashMap<>();
            for (Node node : nodes) {
                parent.put(node, node); // 初始时每个节点的父节点是自己
                size.put(node, 1);      // 初始时每个集合的大小为1
            }
        }

        // 查找父节点（带路径压缩）
        private Node findFather(Node node) {
            Stack<Node> path = new Stack<>();
            while (parent.get(node) != node) {
                path.push(node);
                node = parent.get(node);
            }
            // 路径压缩：把沿途的节点都直接指向最终的父节点
            while (!path.isEmpty()) {
                parent.put(path.pop(), node);
            }
            return node;
        }

        // 判断两个节点是否在同一个集合中
        public boolean isSameSet(Node a, Node b) {
            return findFather(a) == findFather(b);
        }

        // 合并两个节点所在的集合
        public void union(Node a, Node b) {
            if (a == null || b == null) return;
            Node aFather = findFather(a);
            Node bFather = findFather(b);
            if (aFather != bFather) {
                // 小集合挂在大集合下面，保持树的平衡
                int aSize = size.get(aFather);
                int bSize = size.get(bFather);
                Node big = aSize >= bSize ? aFather : bFather;
                Node small = big == aFather ? bFather : aFather;
                parent.put(small, big);
                size.put(big, aSize + bSize);
            }
        }
    }

    // Kruskal 算法主逻辑
    public Set<Edge> kruskalMST(Graph graph) {
        // 1. 将所有边放入一个按权重排序的小根堆（优先队列）
        PriorityQueue<Edge> minHeap = new PriorityQueue<>(Comparator.comparingInt(e -> e.weight));
        for (Edge edge : graph.edges) {
            minHeap.offer(edge);
        }

        // 2. 初始化并查集
        UnionFind uf = new UnionFind(graph.nodes.values());
        // 结果集合
        Set<Edge> result = new HashSet<>();

        // 3. 依次弹出权重最小的边
        while (!minHeap.isEmpty()) {
            Edge edge = minHeap.poll();
            // 如果这条边的两个端点不在同一个连通分量里（不会形成环）
            if (!uf.isSameSet(edge.from, edge.to)) {
                uf.union(edge.from, edge.to); // 合并这两个集合
                result.add(edge);             // 将这条边加入最小生成树
            }
        }
        return result;
    }
}
```



### **2. Prim 算法（普里姆）**

**核心思想：**
“**只看点，向外扩**”。从任意一个节点出发，把它作为初始的生成树。然后每次从**“已经访问过的节点”**指向**“未访问过的节点”**的所有边中，挑一条权重最小的边，把那个未访问的节点拉进生成树。

**关键点：** 需要一个集合记录“解锁”的节点，以及一个小根堆来存放当前所有可选的边

```java
import java.util.*;

public class PrimMST {

    public Set<Edge> primMST(Graph graph) {
        // 小根堆，存放当前所有可选的边（按权重排序）
        PriorityQueue<Edge> minHeap = new PriorityQueue<>(Comparator.comparingInt(e -> e.weight));
        // 记录已经访问过（解锁）的节点
        HashSet<Node> visited = new HashSet<>();
        // 结果集合
        Set<Edge> result = new HashSet<>();

        // 遍历图中的所有节点（防止图不连通，如果是连通图，从任意一点开始即可）
        for (Node node : graph.nodes.values()) {
            if (!visited.contains(node)) {
                // 从当前未访问的节点开始扩展
                visited.add(node);
                // 将该节点的所有出边加入小根堆
                for (Edge edge : node.edges) {
                    minHeap.offer(edge);
                }

                while (!minHeap.isEmpty()) {
                    Edge edge = minHeap.poll();
                    Node toNode = edge.to;
                    // 如果这条边指向的节点还没有被访问过
                    if (!visited.contains(toNode)) {
                        visited.add(toNode);   // 解锁该节点
                        result.add(edge);      // 将这条边加入最小生成树
                        // 将该新节点的所有出边加入小根堆，继续向外扩展
                        for (Edge nextEdge : toNode.edges) {
                            minHeap.offer(nextEdge);
                        }
                    }
                }
            }
        }
        return result;
    }
}
```





## Dijkstra算法

Dijkstra（迪杰斯特拉）算法是解决**带权图单源最短路径**问题的经典算法。它的核心要求是：图中所有边的**权重必须为非负数**。

算法的核心思想是**贪心策略**：从起点出发，每次都从“当前已知的最短路径”中挑一个距离最近的点，用它来更新它的邻居节点的距离，然后把这个点“锁死”（标记为已确定最短路径），不断向外扩散，直到找到终点或遍历完所有节点。

```java
public class Dijkstra {

    // 返回值是一个 HashMap，Key是图中的节点，Value是从起点到该节点的最短距离
    public HashMap<Node, Integer> dijkstra(Node startNode) {
        // 记录从起点到各个节点的最短距离
        HashMap<Node, Integer> distanceMap = new HashMap<>();
        // 记录已经求出最短路径的节点（锁死的节点）
        HashSet<Node> selectedNodes = new HashSet<>();

        // 起点到自己的距离为 0
        distanceMap.put(startNode, 0);

        // 只要还有没被锁定的节点，就继续找
        while (true) {
            // 1. 从 distanceMap 中找出一个距离起点最近、且没被锁定的节点
            Node minNode = getMinDistanceNode(distanceMap, selectedNodes);

            // 如果找不到（说明剩下的节点都不可达），算法结束
            if (minNode == null) {
                break;
            }

            // 2. 把这个节点锁死（标记为已确定最短路径）
            selectedNodes.add(minNode);

            // 3. 用这个节点去更新它所有邻居的距离
            for (Edge edge : minNode.edges) {
                Node toNode = edge.to;
                // 如果邻居还没被锁死，才需要更新
                if (!selectedNodes.contains(toNode)) {
                    // 当前起点到邻居的已知距离（如果还没记录过，默认为无穷大）
                    int oldDistance = distanceMap.getOrDefault(toNode, Integer.MAX_VALUE);
                    // 经过当前 minNode 到达邻居的新距离
                    int newDistance = distanceMap.get(minNode) + edge.weight;

                    // 如果新距离更短，就更新 distanceMap
                    if (newDistance < oldDistance) {
                        distanceMap.put(toNode, newDistance);
                    }
                }
            }
        }
        return distanceMap;
    }

    // 辅助方法：在 distanceMap 中找出距离最小且未被锁定的节点
    private Node getMinDistanceNode(HashMap<Node, Integer> distanceMap, HashSet<Node> selectedNodes) {
        Node minNode = null;
        int minDistance = Integer.MAX_VALUE;

        for (Map.Entry<Node, Integer> entry : distanceMap.entrySet()) {
            Node node = entry.getKey();
            int distance = entry.getValue();
            // 必须是没被锁定的节点，且距离更小
            if (!selectedNodes.contains(node) && distance < minDistance) {
                minNode = node;
                minDistance = distance;
            }
        }
        return minNode;
    }
}
```

### 使用小根堆

辅助方法还可以更快，不需要每次都遍历来查找节点

```java
public class DijkstraQuick {

    public static class NodeRecord {
        public Node node;
        public int distance;

        public NodeRecord(Node node, int distance) {
            this.node = node;
            this.distance = distance;
        }
    }

    public static class NodeHeap {
        private final Node[] nodes;
        // 索引, 记录某个节点在堆中的索引
        private final HashMap<Node, Integer> heapIndexMap;
        // 值，记录某个节点到源点的距离
        private final HashMap<Node, Integer> distanceMap;
        private int size;

        public NodeHeap(int size) {
            nodes = new Node[size];
            heapIndexMap = new HashMap<>();
            distanceMap = new HashMap<>();
            this.size = 0;
        }

        public boolean isEmpty() {
            return size == 0;
        }

        public void addOrUpdateOrIgnore(Node node, int distance) {
            // 如果node在堆中，并且新的距离比原来的距离小，更新
            if (inHeap(node)) {
                distanceMap.put(node, Math.min(distanceMap.get(node), distance));
                insertHeapify(node, heapIndexMap.get(node));
            }
            // 如果node不在堆中，加入
            if (!isEntered(node)) {
                nodes[size] = node;
                heapIndexMap.put(node, size);
                distanceMap.put(node, distance);
                insertHeapify(node, size++);
            }
            // 如果node在堆中，并且新的距离比原来的距离大，忽略
        }

        public NodeRecord pop() {
            NodeRecord nodeRecord = new NodeRecord(nodes[0], distanceMap.get(nodes[0]));
            swap(0, size - 1);
            heapIndexMap.put(nodes[size - 1], -1);
            distanceMap.remove(nodes[size - 1]);
            nodes[size - 1] = null;
            heapify(0, --size);
            return nodeRecord;
        }

        // 插入, 上浮
        private void insertHeapify(Node node, int index) {

            while (distanceMap.get(nodes[index]) < distanceMap.get(nodes[(index - 1) / 2])) {
                swap(index, (index - 1) / 2);
                index = (index - 1) / 2;
            }
        }

        // 调整堆，下沉
        private void heapify(int index, int size) {
            int left = index * 2 + 1;
            while (left < size) {
                int smallest = left + 1 < size && distanceMap.get(nodes[left + 1]) < distanceMap.get(nodes[left])
                        ? left + 1 : left;
                smallest = distanceMap.get(nodes[smallest]) < distanceMap.get(nodes[index]) ? smallest : index;
                if (smallest == index) {
                    break;
                }
                swap(smallest, index);
                index = smallest;
                left = index * 2 + 1;
            }
        }

        private boolean isEntered(Node node) {
            return heapIndexMap.containsKey(node);
        }

        private boolean inHeap(Node node) {
            return isEntered(node) && heapIndexMap.get(node) != -1;
        }

        private void swap(int index1, int index2) {
            heapIndexMap.put(nodes[index1], index2);
            heapIndexMap.put(nodes[index2], index1);
            Node tmp = nodes[index1];
            nodes[index1] = nodes[index2];
            nodes[index2] = tmp;
        }
    }

    public static HashMap<Node, Integer> dijkstra2(Node head, int size) {
        NodeHeap nodeHeap = new NodeHeap(size);
        nodeHeap.addOrUpdateOrIgnore(head, 0);
        HashMap<Node, Integer> result = new HashMap<>();
        while (!nodeHeap.isEmpty()) {
            NodeRecord record = nodeHeap.pop();
            Node cur = record.node;
            int distance = record.distance;
            for (Edge edge : cur.edges) {
                nodeHeap.addOrUpdateOrIgnore(edge.to, edge.weight + distance);
            }
            result.put(cur, distance);
        }
        return result;
    }


}
```

# 前缀树

前缀树，英文叫 **Trie**（发音类似 "try"），又被称为**字典树**或**单词查找树**。它是一种特殊的 **N叉树**（多叉树）。

它的核心设计思想是：**利用字符串的公共前缀来减少查询时间，最大限度地减少无谓的字符串比较。**

你可以把它想象成一本字典的目录：从根节点出发，沿着字母往下走，每走一步就确定了一个字符，走到某个节点时，就能拼出一个完整的单词。

### 三大性质：

1. **根节点不包含字符**：根节点仅仅代表“起点”，除了根节点外，每个节点都只包含一个字符。
2. **路径即单词**：从根节点到树中任意一个节点，路径上经过的字符连接起来，就是该节点对应的字符串。
3. **子节点不重复**：同一个节点的所有子节点中，包含的字符互不相同。（比如一个节点下不可能有两个 'a' 子节点）。

```java
package recursion;

public class C01_TrieTree {

    public static class TrieNode{
        public int pass;
        public int end;
        public TrieNode[] nexts;
        public TrieNode(){
            pass = 0;
            end = 0;
            nexts = new TrieNode[26];
        }
    }

    public static class Trie{
        TrieNode root;
        public Trie(){
            root = new TrieNode();
        }

        public void insert(String word){
            if (word == null)
                return ;
            TrieNode node = root;
            char[] chars = word.toCharArray();
            int index = 0;
            for(char ch : chars){
                index = ch - 'a';
                if (node.nexts[index] == null)
                    node.nexts[index] = new TrieNode();
                node = node.nexts[index];
                node.pass++;
            }
            node.end++;
        }

        public int search(String word){
            if (word == null)
                return 0;
            TrieNode node = root;
            char[] chars = word.toCharArray();
            int index = 0;
            for(char ch : chars){
                index = ch - 'a';
                if (node.nexts[index] == null)
                    return 0;
                node = node.nexts[index];
            }
            return node.end;
        }

        public int prefixNumber(String word){
            if (word == null)
                return 0;
            TrieNode node = root;
            char[] chars = word.toCharArray();
            int index = 0;
            for(char ch : chars){
                index = ch - 'a';
                if (node.nexts[index] == null)
                    return 0;
                node = node.nexts[index];
            }
            return node.pass;
        }

        public void delete(String word){
            if(search(word) == 0)
                return;
            TrieNode node = root;
            char[] chars = word.toCharArray();
            node.pass--;
            int index = 0;
            for(char ch : chars){
                index = ch - 'a';
                if( --node.nexts[index].pass == 0) {
                    node.nexts[index] = null;
                    return ;
                }
                node = node.nexts[index];
            }
            node.end--;
        }
    }


    static void main() {
        Trie trie = new Trie();
        System.out.println(trie.search("zuo")); // 0
        trie.insert("zuo");

        trie.delete("zuo");
        System.out.println(trie.search("zuo")); // 0
        trie.insert("zuo");
        trie.insert("zuo");
        trie.delete("zuo");
        System.out.println(trie.search("zuo"));  // 1
        trie.delete("zuo");
        System.out.println(trie.search("zuo")); // 0
        trie.insert("zuoa");
        trie.insert("zuoac");
        trie.insert("zuoab");
        trie.insert("zuoad");
        trie.delete("zuoa");
        System.out.println(trie.search("zuoa")); // 0
        System.out.println(trie.prefixNumber("zuo"));  // 3
    }



}
```

# 贪心算法

通俗地讲，贪心算法就是**“目光短浅、只看眼前”**的策略。

它并不从整体最优上加以考虑，而是在每一步选择时，都采取在当前状态下**最好或最优（即最有利）的选择**。希望通过一系列局部的最优解，最终推导出全局的最优解。

### **贪心算法的核心要素**

要想使用贪心算法，一个问题必须具备两个重要性质：

1. **贪心选择性质**：整体的最优解可以通过一系列局部的最优选择来达到。也就是说，你当前的这一步最优选择，不会导致后面的路走不通或者错过真正的全局最优解。
2. **最优子结构**：一个问题的最优解，包含了其子问题的最优解。（这一点和动态规划很像）。

### **贪心 vs 动态规划（DP）：最容易混淆的考点**

很多同学分不清什么时候用贪心，什么时候用DP。老师给你总结一个核心区别：

- **贪心算法是“一条道走到黑”**：一旦做出了当前的局部最优选择，就**绝不回头**。它不保留子问题的所有可能状态。
- **动态规划是“全面撒网，重点培养”**：它会考虑所有的可能性，通过状态转移方程来记录子问题的状态，甚至会在后续步骤中推翻之前的某些选择。

*一句话总结：如果当前的选择会影响未来的决策空间，那大概率不能用贪心，得用 DP；如果当前选了之后，剩下的问题和原来的问题性质完全一样，只是规模变小了，那就可以尝试贪心。*

```java
	public static int findMaximizedCapital(int k, int W, int[] Profits, int[] Capital) {
		Node[] nodes = new Node[Profits.length];
		for (int i = 0; i < Profits.length; i++) {
			nodes[i] = new Node(Profits[i], Capital[i]);
		}

		PriorityQueue<Node> minCostQ = new PriorityQueue<>(new MinCostComparator());
		PriorityQueue<Node> maxProfitQ = new PriorityQueue<>(new MaxProfitComparator());
		for (int i = 0; i < nodes.length; i++) {
			minCostQ.add(nodes[i]);
		}
		for (int i = 0; i < k; i++) {
			while (!minCostQ.isEmpty() && minCostQ.peek().c <= W) {
				maxProfitQ.add(minCostQ.poll());
			}
			if (maxProfitQ.isEmpty()) {
				return W;
			}
			W += maxProfitQ.poll().p;
		}
		return W;
	}
```

```java
				this.minHeap.add(this.maxHeap.poll());

			} else {
				minHeap.add(num);
			}
			modifyTwoHeapsSize();

			int minHeapSize = this.minHeap.size();

				return null;
			}
			Integer maxHeapHead = this.maxHeap.peek();
			Integer minHeapHead = this.minHeap.peek();
			if (((maxHeapSize + minHeapSize) & 1) == 0) {

			}
			return maxHeapSize > minHeapSize ? maxHeapHead : minHeapHead;
		}
```

# N皇后

N皇后问题（N-Queens Problem）是一个经典的组合优化与回溯算法问题。

**1. 问题定义**
在 N×N*N*×*N* 的国际象棋棋盘上，放置 N*N* 个皇后，使得它们彼此之间不能相互攻击。

**2. 约束条件**
根据国际象棋规则，任意两个皇后不能处于：

- 同一行
- 同一列
- 同一对角线（包括主对角线和副对角线）

**3. 算法求解思路**
该问题通常使用**回溯算法（Backtracking）**结合**深度优先搜索（DFS）**来求解。

核心逻辑为逐行放置皇后：

1. 从第一行开始，尝试在当前行的每一列放置一个皇后。
2. 检查当前位置是否合法（即不与已放置的皇后冲突）。
3. 若合法，则递归进入下一行继续放置；若不合法，则跳过该列。
4. 若当前行的所有列均无法放置，则回溯到上一行，撤销上一次的选择并尝试其他列。
5. 当成功在第 N*N* 行放置完皇后时，记录一种有效解。

**4. 冲突检测优化**
为了将判断冲突的时间复杂度降至 O(1)*O*(1) ，通常使用三个哈希集合或布尔数组来记录已占用的位置：

- **列集合**：记录已被占用的列索引。
- **主对角线集合**：主对角线上所有格子的 `行号 - 列号` 值相同。
- **副对角线集合**：副对角线上所有格子的 `行号 + 列号` 值相同。

```java
		}
		int res = 0;
		for (int j = 0; j < n; j++) {

			}

		for (int k = 0; k < i; k++) {

				return false;
			}
		}
		return true;

	public static int process2(int upperLim, int colLim, int leftDiaLim,
			int rightDiaLim) {
		if (colLim == upperLim) {
			return 1;
		}
		int pos = 0;
		int mostRightOne = 0;
		pos = upperLim & (~(colLim | leftDiaLim | rightDiaLim));

		while (pos != 0) {

					(leftDiaLim | mostRightOne) << 1,
					(rightDiaLim | mostRightOne) >> 1);
		}
		return res;
	}
```

## 汉诺塔

### **1. 问题定义**

有三根柱子（通常记为 A、B、C），初始时在柱子 A 上从下到上按大小顺序叠放着 N*N* 个圆盘。目标是将所有圆盘从柱子 A 移动到柱子 C。

### **2. 约束条件**

- 每次只能移动一个圆盘。
- 大圆盘不能放在小圆盘上面。

### **3. 算法求解思路（递归思想）**

要将 N*N* 个圆盘从 A 移动到 C，可以分解为以下三个步骤：

1. 将 A 柱上的前 N−1*N*−1 个圆盘，借助 C 柱，移动到 B 柱。
2. 将 A 柱上剩下的第 N*N* 个圆盘（最大的圆盘），直接移动到 C 柱。
3. 将 B 柱上的 N−1*N*−1 个圆盘，借助 A 柱，移动到 C 柱。

当 N=1*N*=1 时，直接将圆盘从 A 移动到 C 即可，这是递归的基准情况（Base Case）。

### **4. 复杂度分析**

- **时间复杂度**： O(2N)*O*(2*N*) 。移动 N*N* 个圆盘所需的总步数公式为 2N−12*N*−1 。
- **空间复杂度**： O(N)*O*(*N*) 。由递归调用栈的深度决定。

```java
    /**
     * 主函数：计算获胜者的分数
     */
    public static int winner(int[] arr) {
        if (arr == null || arr.length == 0) {
            return 0;
        }
        // 计算整个数组范围内，先手和后手各自能拿到的最大分数
        int firstScore = first(arr, 0, arr.length - 1);
        int secondScore = second(arr, 0, arr.length - 1);

        // 返回两者中的较大值
        return Math.max(firstScore, secondScore);
    }

    /**
     * 递归函数：计算在 arr[L...R] 范围内，作为【先手】能获得的最大分数
     */
    public static int first(int[] arr, int L, int R) {
        // 基准情况：只有一张牌，先手直接拿走
        if (L == R) {
            return arr[L];
        }

        // 选择1：拿走左边的牌 arr[L]
        // 剩下 arr[L+1...R]，此时我变成后手
        int pickLeft = arr[L] + second(arr, L + 1, R);

        // 选择2：拿走右边的牌 arr[R]
        // 剩下 arr[L...R-1]，此时我变成后手
        int pickRight = arr[R] + second(arr, L, R - 1);

        // 绝顶聪明：选择收益最大的方案
        return Math.max(pickLeft, pickRight);
    }

    /**
     * 递归函数：计算在 arr[L...R] 范围内，作为【后手】能获得的最大分数
     */
    public static int second(int[] arr, int L, int R) {
        // 基准情况：只有一张牌，被先手拿走了，后手得分为 0
        if (L == R) {
            return 0;
        }

        // 这里的逻辑稍微绕一点：
        // 后手是没有选择权的。后手的得分取决于先手怎么选。
        // 先手也是绝顶聪明的，他会选择让他自己得分最高的方案。
        // 但是，无论先手选左边还是右边，剩下的局面对于当前的“后手”来说，
        // 他就变成了那个剩余局面的“先手”。

        // 如果先手拿了左边 (arr[L])，剩下 [L+1...R]，我变成该范围的先手
        int remainIfLeftPicked = first(arr, L + 1, R);

        // 如果先手拿了右边 (arr[R])，剩下 [L...R-1]，我变成该范围的先手
        int remainIfRightPicked = first(arr, L, R - 1);

        // 关键点：
        // 在标准的极小极大算法中，通常假设对手会让你得分最小。
        // 但在这种“总分固定”或者“零和/非零和”的取牌游戏中，
        // 其实有一个隐含逻辑：先手做出了最优选择（Max），导致局面确定。
        // 而后手在这个确定的局面下，只能获得对应的分数。
        //
        // 实际上，对于后手函数 `second(L, R)`，它的返回值应该等于：
        // 在先手选择了最优策略后，留给我的那个局面的 `first` 值。
        // 但由于 `first` 函数内部已经做了 Max 决策，
        // 这里我们需要理解：先手选了 Max(自己)，剩下的自然就是给我的。
        // 在数学上，这等价于先手选了之后，我在剩下的里面取 First。
        // 而先手会倾向于让自己分高，这往往意味着让我分低（如果是零和）。
        // 但在这种特定递归结构下，正确的逻辑是：
        // 后手得到的分数 = min(先手拿左后我作为先手的分, 先手拿右后我作为先手的分)
        // 为什么是 Min？因为先手会选对他有利的（也就是对我相对不利的）。
        // 如果先手拿左边能得100分，拿右边只能得10分，他肯定拿左边。
        // 那我就只能得到“他拿左边后剩下的局面”的分数。

        return Math.min(remainIfLeftPicked, remainIfRightPicked);
    }

        // 示例 1
        int[] arr1 = {1, 2, 100, 4};
        System.out.println("示例 1 结果: " + winner(arr1)); // 预期输出: 101

        // 示例 2
        int[] arr2 = {1, 100, 2};
        System.out.println("示例 2 结果: " + winner(arr2)); // 预期输出: 100
    }
```
